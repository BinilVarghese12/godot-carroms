# Carrom – Godot Game

A two-player digital carrom game developed in **Godot using GDScript** for my A-level Computer Science project.


## Overview

The game recreates carrom with physics-based movement, automatic rule handling and a complete user interface. I designed, programmed and tested the project through multiple prototypes, improving it using user feedback.

## Features

- Drag-to-aim shooting system
- Adjustable shot power
- Physics-based collisions and friction
- Automatic pocket detection and scoring
- Foul detection and turn rotation
- Player-name entry
- Difficulty and settings controls
- Winner detection and results screen

## Technical Highlights

- Built gameplay systems using GDScript
- Used object-oriented and event-driven programming
- Managed interactions between multiple scenes and scripts
- Applied validation, testing and iterative development
- Fixed issues involving scoring, physics and game state

## Project Structure

- `assets/` – images and other visual resources
- `scenes/` – Godot scene files
- `scripts/` – gameplay and interface code
- `project.godot` – main Godot project file
